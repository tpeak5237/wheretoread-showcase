# Security and privacy boundaries

This is an offline, frontend demonstration. All bundled records are synthetic.
There is no backend, authentication, authorization, database, analytics, or API integration.
Client-side roles and workflows illustrate UI behavior only; they cannot enforce access.
Local browser storage is user-controlled and must never contain secrets or sensitive records.
No real institution, customer, infrastructure, or provider is connected.

Report a vulnerability using GitHub's private vulnerability reporting if enabled.
Otherwise open an issue requesting a private contact channel without disclosing exploit details,
credentials, or personal data. Never post secrets in a public issue.

Security checks reduce known release risks; they do not establish production readiness.
A deployed real service requires a separate threat model and server-side controls.
