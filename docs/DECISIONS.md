# Decisions

- Independently authored for this public edition; no private Git history or implementation copied.
- Static React + TypeScript + Vite keeps the demo reproducible without credentials or services.
- Fixtures are deterministic synthetic records. Browser-local state is presentation state.
- System Thai/Latin fonts avoid a font download or redistributing unclear assets.
- Original CSS/SVG artwork and ISC Lucide icons avoid stock-photo licensing and remote calls.
- MIT applies to independently authored project code. Installed packages retain their licenses.
- CI builds and tests the static demonstration; it does not deploy an application.
