# Contributing

Use Node.js 24 and `npm ci`. Create a feature branch, keep changes focused, and run
`npm run check` and `npm run test:e2e` (install Chromium first).
Include a screenshot for interface changes and describe accessibility verification.
Use fictional data and original or appropriately licensed assets only. Do not add
production endpoints, credentials, analytics, backend code, or copied private history.
Tests should exercise observable behavior. Describe limitations honestly.
